# Boxi Yu's website

An academic website for Boxi Yu's research, publications, and service, built with Astro.

## Quick start

Use Node 24 LTS and npm.

```sh
npm ci
npm run dev
```

Run `npm run verify` before release. Production builds exclude editorial drafts.
